About this archive and adding photos

This static GitHub Pages project has no configured licensed NFL photo API, media feed, or server-side updater. New photos are not discovered automatically. To add an entry, add a unique record to photos-data.js with an image URL or local path, the correct NFL season, week or event, caption, verified team IDs, player names when known, and source/attribution details. Add the image file to the project when permitted. Do not copy or hotlink a provider's image unless its license and terms allow it; use a provider's official API and server-side credentials only if one is later configured.

Seasons are labeled by NFL season, not image upload or calendar date. A January or February postseason image belongs to the season that began the previous fall. Unknown dates and attribution remain unspecified rather than being inferred.
